## 签名

1. **每个参数，调用方实际有几种可能的值？**　只有一种 → 它不是参数，是噪音，删掉。
2. **实现动了签名里没提到的东西吗？**　动了 → 签名在说谎。

> 2026-09-12 `Connection::send(const char *buf, size_t len)` 两条全犯：
> 调用方只可能传 `output_`（犯 ①），实现却去扣 `output_` 的账、而签名里根本没有 `output_`（犯 ②）。
> 改成无参 `send()` 后，`conn.send("PONG\r\n", 6)` 这种写法**在语言层面消失**——不靠记性挡。

## 表达式

4. **每个比较都写全主语。**　`a == X || a == Y`，不是 `a == X || Y`，更不是 `a == (X || Y)`。
   同族：`0 < x < 10` 永远为真；`a & b == c` 会被读成 `a & (b==c)`。
   **`-Wall -Wextra -Wlogical-op` 全都不报警**（2026-09-12 实测），只能靠念这一条。

5. **比较字符串前先问：两边是 `char*` 还是 `std::string`？**　`char*` 的 `==` 比的是**地址**，永远为假。
   用 `std::string(p) == "x"` 或 `strcmp(p, "x") == 0`。`argv[i]`、字符串字面量都是 `char*`。
