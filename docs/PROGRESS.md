### B1 已讨论的设计

- 过期记录在语义上视为不存在；`PERSIST` 不能复活已过期 key。
- 第一版惰性删除：访问时发现过期，先删除，再返回不存在。重复检查和清理逻辑准备抽辅助函数，接口尚待设计。
- 当前 `Entry` 保持为 MemStore 内部类型。曾讨论通过扩展 `IStore::set` 参数传入可选截止时间；**扩展函数参数仍然是修改接口**，需同步派生类和调用方。自定义过期字典接入后截止时间如何归属，尚待设计，不能默认两处重复保存。
- `SET key value EX seconds` 在原定范围内，尚未实现；普通 `SET` 覆盖旧值时清除旧过期时间。
- 定时器继续使用 `steady_clock`；持久化截止时间计划使用 `system_clock` 对应的 Unix 毫秒数。RocksDB 值与过期元数据的编码尚未实现。
